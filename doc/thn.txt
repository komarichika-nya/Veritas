1. Scene / Primitive / Aggregate 三层不该塌成一个 BVH。
图里"Camera → BVH"这个箭头是信号——你把 BVH 当成顶层概念了。pbrt 的做法是：Shape（纯几何求交，三角形/球/曲线）→ Primitive（Shape + Material + AreaLight + MediumInterface）→ Aggregate（也是 Primitive，但内部装着子 Primitive，BVH/Kd-tree/Embree/OptiX 都是它的实现）→ Scene。这样 BVH 只是 Aggregate 的一种实现，未来要换 Embree、OptiX、甚至两层 BVH（TLAS/BLAS for instancing）才不需要伤筋动骨。Hit 里要带 instance id 就是因为有这层。
**2. Integrator 抽象缺失。**你图里"shader 入口构造 SurfaceInteraction → 采样 BSDF/Light → 新光线"这就是一个硬编码的 path integrator。pbrt 的 Integrator 是顶层概念，下面有 PathIntegrator、BDPT、MLT、SPPM、VolPath、LightTracer……如果你没把这层抽象出来，将来想加双向就要重写主循环。建议现在就把"一个 pixel 怎么从 Camera 走到累加 L"这个流程封装成 Integrator::Li(ray, scene, sampler)。
**3. Spectrum 完全没有。**你 Path::beta, L 现在是 vec3<T>（顺手提一句这个还少了 tag，编不过）。pbrt 一个核心抽象就是 SampledSpectrum / RGBSpectrum。媲美 pbrt 必须能切 spectral rendering，否则色散、薄膜干涉、荧光全做不了。早期可以全用 RGB，但接口要预留好。
**4. Medium / PhaseFunction（参与介质）。**雾、烟、次表面散射、体积渲染——这些 pbrt 都有。你的 ray-march 流程要在"和 Surface 求交"和"调 BSDF"之间插一个"沿 ray 采样 Medium，可能在介质内部 scatter 而非到达 surface"的分支。这个不在你图里。
**5. Film / Filter。**你只有 Pixel.tot，没有重建滤波（Box/Triangle/Gaussian/Mitchell-Netravali/Lanczos）、没有 tile 调度、没有 splat（BDPT/光子贴图需要任意像素 splat 而不是 add 到当前像素）、没有 AOV（normal/albedo/depth pass，给降噪器用）。
**6. Light 体系。**单独一个 "Light 节点"撑不起来。pbrt：Light 基类 → PointLight/SpotLight/DistantLight/AreaLight/InfiniteAreaLight/PortalLight，加上场景级的 LightSampler（uniform / power / LightBVH）。环境贴图的重要性采样、many-light 场景的 LightBVH 都是大块工作。
**7. Material 和 BSDF 要分开。**你图里写"Material/BSDF"放一起。实际 Material::GetBSDF(SurfaceInteraction, allocator) 返回 BSDF，BSDF 内部装多个 BxDF（Lambert、Microfacet、Specular、Disney 各 lobe……）。这个分层让 layered material 和 mix material 自然实现。BSDF 还要在 shading frame 内工作，Material 负责 normal mapping、bump mapping、纹理求值。
8. Texture 抽象。Texture<float>、Texture<Spectrum>，常量 / image / 程序化 / mix / scale，UV 映射——这些 pbrt 都是独立模块。
**9. Transform / AnimatedTransform。**你 Cp::t 已经有时间字段了，方向对的，但还需要 AnimatedTransform（两个 Transform + key time，做 SQT 分解后插值），运动模糊和 BVH 的 motion-aware bbox 都靠它。你的 mat34::decompose 已经写了，再加上 SLERP（你也有了）就基本够用。
**10. MIS 不是"再说"而是要架构里有。**至少 BSDF 和 Light 各自的 sample/pdf 接口都要给出"另一个采样策略下如果采到这个方向 pdf 是多少"的能力。Delta 分布的特殊处理（pdf=∞ / pdf=0）要从一开始就想好。
**11. Wavefront vs Megakernel——既然你写了 HD 宏，这个决定要早做。**pbrt-v4 在 GPU 上用 wavefront：把 ray gen / closest-hit / shadow / shading 拆成不同 queue，每个 kernel 做一类工作，缓解寄存器压力和 SIMT divergence。如果你打算只跑 CPU，megakernel（一个 kernel 跑完整 path）就够。但你要 GPU 性能能打，megakernel 在材质/光源种类多了之后会被寄存器和 divergence 拖死。这个选择会反过来塑造你整个 Integrator 接口的形态——wavefront 下"递归调用 BVH"是不存在的，全是 SoA + queue。4

template<typename T>HD quat<T>quat<T>::matr(const mat34<T>&v){
T t=v.mat[0][0]+v.mat[1][1]+v.mat[2][2];quat<T>ans;
if(t>0){T s=T(2)*sqrt(t+T(1)),s1=T(1)/s;ans.w=T(0.25)*s;
ans.x=(v.mat[2][1]-v.mat[1][2])*s1;ans.y=(v.mat[0][2]-v.mat[2][0])*s1;ans.z=(v.mat[1][0]-v.mat[0][1])*s1;}
else if(v.mat[0][0]>v.mat[1][1]&&v.mat[0][0]>v.mat[2][2]){T s=T(2)*sqrt(T(1)+v.mat[0][0]-v.mat[1][1]-v.mat[2][2]),s1=T(1)/s;ans.w=(v.mat[2][1]-v.mat[1][2])*s1;ans.x=T(0.25)*s;
ans.y=(v.mat[0][1]+v.mat[1][0])*s1;ans.z=(v.mat[0][2]+v.mat[2][0])*s1;}
else if(v.mat[1][1]>v.mat[2][2]){T s=T(2)*sqrt(T(1)+v.mat[1][1]-v.mat[0][0]-v.mat[2][2]),s1=T(1)/s;
ans.w=(v.mat[0][2]-v.mat[2][0])*s1;ans.x=(v.mat[0][1]+v.mat[1][0])*s1;ans.y=T(0.25)*s;ans.z=(v.mat[1][2]+v.mat[2][1])*s1;}
else{T s=T(2)*sqrt(T(1)+v.mat[2][2]-v.mat[0][0]-v.mat[1][1]),s1=T(1)/s;ans.w=(v.mat[1][0]-v.mat[0][1])*s1;
ans.x=(v.mat[0][2]+v.mat[2][0])*s1;ans.y=(v.mat[1][2]+v.mat[2][1])*s1;ans.z=T(0.25)*s;}return norm(ans);}

HD void mat34<T>::decompose(const mat34<T>&v,vec3<T,V>&t,quat<T>&q,vec3<T,V>&s){
t=vec3<T,V>(v.mat[0][3],v.mat[1][3],v.mat[2][3]);
T sx=sqrt(v.mat[0][0]*v.mat[0][0]+v.mat[1][0]*v.mat[1][0]+v.mat[2][0]*v.mat[2][0]);
T sy=sqrt(v.mat[0][1]*v.mat[0][1]+v.mat[1][1]*v.mat[1][1]+v.mat[2][1]*v.mat[2][1]);
T sz=sqrt(v.mat[0][2]*v.mat[0][2]+v.mat[1][2]*v.mat[1][2]+v.mat[2][2]*v.mat[2][2]);
mat34<T>r=v;s=vec3<T,V>(sx,sy,sz);
// printf("%f %f %f\n",sx,sy,sz);
if(sx!=0)r.mat[0][0]/=sx,r.mat[1][0]/=sx,r.mat[2][0]/=sx;
if(sy!=0)r.mat[0][1]/=sy,r.mat[1][1]/=sy,r.mat[2][1]/=sy;
if(sz!=0)r.mat[0][2]/=sz,r.mat[1][2]/=sz,r.mat[2][2]/=sz;
if(det(r)<T(0)){s.x=-s.x;r.mat[0][0]=-r.mat[0][0],r.mat[1][0]=-r.mat[1][0],r.mat[2][0]=-r.mat[2][0];}
q=quat<T>::matr(r);}
